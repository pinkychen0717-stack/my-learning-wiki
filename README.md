# My Learning Wiki

**Personal Learning Knowledge Base｜個人學習知識庫**

## 專案簡介

My Learning Wiki 是一個個人學習知識庫網站，主要整理大學生在程式設計、人工智慧及大學課程中學習到的知識。

本專案透過 Markdown 整理學習文章，並使用 HTML、CSS 與 JavaScript 建立網站，讓使用者能夠瀏覽、搜尋及閱讀不同領域的知識內容。

專案同時建立 AGENTS.md，制定 AI 開發規則，使 AI 能夠依照統一的架構及格式持續新增與維護文章。

## 網站分類

### 1. Programming（程式設計）
- C++ 程式設計入門

### 2. Artificial Intelligence（人工智慧）
- 機器學習入門

### 3. Course Notes（課程筆記）
- 資料結構入門

## 網站功能

- 個人學習知識庫首頁
- 三大知識分類
- 分類搜尋功能
- Markdown 文章閱讀
- 共用文章閱讀版型
- 支援電腦及手機瀏覽

## 使用技術

| 技術 | 用途 |
|---|---|
| HTML | 建立網頁結構 |
| CSS | 設計網站外觀 |
| JavaScript | 實作搜尋及文章載入功能 |
| Markdown | 整理知識文章 |
| Marked.js | 將 Markdown 轉換成 HTML |
| GitHub Pages | 公開網站 |

## AI 開發規則

本專案使用 AGENTS.md 作為 AI 開發規範。

AI 在新增或修改內容之前，應先閱讀 AGENTS.md，並遵守其中的檔案管理、文章格式、網站設計及程式碼修改規則。

透過統一的規範，讓未來新增知識文章時，可以沿用原有的網站架構及閱讀版型。
