# 機器學習入門
## 一、什麼是機器學習？
機器學習（Machine Learning）是人工智慧（Artificial Intelligence）的一個重要領域。
它讓電腦能夠透過資料進行學習，找出資料中的規律，並利用學習到的結果進行預測或分類，而不需要為每一種情況都明確撰寫規則。
## 二、機器學習的主要類型
### 1. 監督式學習（Supervised Learning）
透過具有標籤的資料進行訓練，讓模型學習輸入與正確答案之間的關係。
例如：
- 電子郵件垃圾訊息分類
- 房價預測
- 圖片辨識
### 2. 非監督式學習（Unsupervised Learning）
使用沒有標籤的資料，讓模型自行尋找資料中的結構或規律。
例如：
- 顧客分群
- 資料分群
- 異常資料偵測
### 3. 強化學習（Reinforcement Learning）
透過與環境互動，根據獎勵或懲罰調整行為，逐步學習較好的決策方式。
例如：
- 遊戲 AI
- 機器人控制
- 自動化決策
## 三、機器學習的基本流程
1. 收集資料。
2. 整理及清理資料。
3. 選擇適合的模型。
4. 使用資料訓練模型。
5. 評估模型表現。
6. 使用模型進行預測。
## 四、常見的機器學習演算法
| 演算法 | 主要用途 |
|---|---|
| Linear Regression | 線性迴歸與數值預測 |
| Logistic Regression | 分類問題 |
| Decision Tree | 決策與分類 |
| K-Nearest Neighbors | 分類與預測 |
| K-Means | 分群 |
| Random Forest | 分類與迴歸 |
## 五、機器學習的應用
- 醫療：協助分析醫療影像。
- 金融：信用風險評估。
- 零售：商品推薦。
- 交通：交通流量預測。
- 日常生活：語音辨識與人臉辨識。
## 六、學習重點整理
- 機器學習是人工智慧的重要領域。
- 主要分成監督式、非監督式及強化學習。
- 模型需要透過資料進行訓練。
- 不同演算法適合不同類型的問題。
- 模型訓練完成後，仍需要評估其表現。
