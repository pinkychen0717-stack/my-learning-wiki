# C++ 程式設計入門
## 一、什麼是 C++？
C++ 是一種通用型程式設計語言，廣泛應用於軟體開發、遊戲製作、系統程式及演算法設計。
C++ 是由 C 語言延伸發展而來，除了支援程序導向程式設計，也支援物件導向程式設計。
## 二、C++ 的主要特色
1. **執行效率高：** 可以直接編譯成機器碼，適合需要高效能的應用程式。
2. **物件導向：** 支援類別、物件、繼承及多型。
3. **靈活性高：** 提供指標、記憶體管理等功能。
4. **應用範圍廣：** 可用於遊戲、系統軟體及演算法開發。
## 三、第一個 C++ 程式
以下是一個簡單的 Hello World 範例：
```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "Hello World!" << endl;
    return 0;
}
```
### 程式碼說明
- `#include <iostream>`：引入輸入與輸出功能。
- `using namespace std;`：使用標準命名空間。
- `int main()`：程式執行的主要入口。
- `cout`：輸出文字。
- `endl`：換行。
- `return 0;`：表示程式正常結束。
## 四、常見的 C++ 基本資料型態
| 資料型態 | 用途 | 範例 |
|---|---|---|
| int | 整數 | 10 |
| float | 單精度浮點數 | 3.14 |
| double | 雙精度浮點數 | 3.14159 |
| char | 單一字元 | 'A' |
| string | 字串 | "Hello" |
| bool | 布林值 | true |
## 五、學習重點整理
- C++ 是一種高效能的程式設計語言。
- `main()` 是程式執行的入口。
- `cout` 可以輸出資料。
- 資料型態用來決定變數可以儲存的資料種類。
- 熟悉基本語法是學習資料結構與演算法的重要基礎。
