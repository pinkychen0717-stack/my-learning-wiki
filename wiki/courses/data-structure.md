# 資料結構入門
## 一、什麼是資料結構？
資料結構（Data Structure）是指資料在電腦中組織、儲存及管理的方式。
透過適當的資料結構，可以讓程式更有效率地存取、搜尋、修改及處理資料。
資料結構也是學習演算法與程式設計的重要基礎。
## 二、常見的資料結構
### 1. 陣列（Array）
陣列是一種可以儲存多筆相同型態資料的結構，透過索引值存取元素。
例如：
```cpp
int numbers[5] = {1, 2, 3, 4, 5};
```
### 2. 鏈結串列（Linked List）
鏈結串列由多個節點組成，每個節點包含資料及指向下一個節點的指標。
特色：
- 可以動態增加或刪除節點。
- 不需要連續的記憶體空間。
- 必須透過指標尋找節點。
### 3. 堆疊（Stack）
堆疊採用 LIFO（Last In, First Out），也就是後進先出。
常見操作：
- Push：加入元素。
- Pop：移除最上方元素。
- Top：查看最上方元素。
### 4. 佇列（Queue）
佇列採用 FIFO（First In, First Out），也就是先進先出。
常見操作：
- Enqueue：加入元素。
- Dequeue：移除最前方元素。
- Front：查看最前方元素。
### 5. 樹（Tree）
樹是一種階層式資料結構，由節點及節點之間的關係組成。
常見應用：
- 檔案系統。
- 搜尋樹。
- 資料庫索引。
### 6. 圖形（Graph）
圖形由頂點（Vertex）及邊（Edge）組成，可以用來表示不同節點之間的關係。
常見應用：
- 社群網路。
- 地圖導航。
- 交通路線。
## 三、常見資料結構比較
| 資料結構 | 主要特色 |
|---|---|
| Array | 使用索引存取資料 |
| Linked List | 透過指標連接節點 |
| Stack | 後進先出 |
| Queue | 先進先出 |
| Tree | 階層式結構 |
| Graph | 表示節點之間的關係 |
## 四、資料結構的重要性
1. 提高資料存取效率。
2. 幫助設計更有效率的演算法。
3. 讓程式更容易管理大量資料。
4. 解決不同類型的計算問題。
## 五、學習重點整理
- 資料結構負責組織及管理資料。
- 陣列可以透過索引存取元素。
- Stack 採用 LIFO。
- Queue 採用 FIFO。
- Tree 適合表示階層關係。
- Graph 適合表示複雜的關聯。
## 六、延伸學習
建議接下來學習：
1. 陣列與鏈結串列。
2. 堆疊與佇列。
3. 樹與二元搜尋樹。
4. 圖形及圖形搜尋。
5. 排序與搜尋演算法。
